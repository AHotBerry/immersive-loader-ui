# 🌌 Immersive System Loading Screen

A complex, high-fidelity loading screen featuring animated graphic rings, a pulsing core, sequential step-by-step status updates, a dynamic progress bar, and interactive ambient background particles. Designed with a sleek, dark-mode glassmorphism aesthetic.

---

## ✨ Key Features

* **🎨 Glassmorphism & Neon Aesthetics:** Built using modern CSS styling, featuring frosted glass panels (`backdrop-filter: blur`), glowing radial core elements, and vibrant gradient accents.
* **⚙️ Dual-Ring Animated Core:** Features dual counter-rotating loading rings (`spin` and `spin-reverse` animations) with a breathing pulse effect.
* **📊 Sequential Progress Controller:** Simulates realistic system boot sequences with dynamic milestone delays (e.g., pausing briefly at critical steps like connecting to servers or compiling assets).
* **✨ Ambient Particle Engine:** Includes an HTML5 Canvas-based background particle system that renders drifting, semi-transparent floating nodes for a living atmosphere.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic layout structure and canvas element integration.
* **CSS3:** Custom properties (CSS variables), keyframe animations, Flexbox layout, and backdrop filters.
* **JavaScript (Vanilla):** Custom object-oriented particle engine using `requestAnimationFrame` and asynchronous sequential progress state management.
